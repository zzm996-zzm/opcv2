# 增长测算 MVP 后续开发记录

本文记录增长测算按需求文档顺序推进时的交付边界、接口闭环和待确认问题。MVP 先保证前后端真实对接、按钮可用、结果可追溯，再逐步补齐算法和运营能力。

## 已完成

- 自然语言业务描述创建测算草稿。
- 后端提取基础参数并返回缺失问题，前端补充后提交。
- 创建模型、保存不可变快照、展示漏斗/情景/预测/建议。
- 报告页支持按 `model_id` 定位指定模型。
- 历史页支持名称搜索、服务端分页、查看报告和再次测算。
- 报告页支持导出 JSON 文件，导出内容带模型版本和免责声明。
- 历史页支持选择 2–4 个模型，进入对比页查看核心指标和关键假设。
- 报告页支持规则化风险诊断，显示整体等级、当前值、阈值、原因和建议。
- 报告页支持 90 天行动计划，按阶段展示行动项、责任角色、目标指标和预期结果。
- 报告页支持输入来源、可信度、单位和用户确认状态展示。
- 历史页支持近 7/30/90 天时间范围筛选，筛选状态同步 URL 并由后端分页查询。
- 增长建议生成任务前先预览，确认后再写入任务中心。
- 收入预测支持 1–36 个月后端参数，前端提供 3/5/12 个月快捷周期。
- 风险规则输出规则版本和结构化阈值，服务支持通过构造选项替换整套阈值。
- 历史页支持业务类型、完成状态、风险等级筛选，以及创建时间、收入和利润率排序。
- 行动计划阶段和行动 ID 会进入任务生成上下文；确认创建后报告页展示任务 ID 和任务中心入口。

## 开发顺序

1. 输入与追问闭环：已完成。
2. 历史、指定报告、再次测算：已完成。
3. MVP 报告 JSON 导出：已完成。
4. 报告对比：已完成选择 2–4 个历史版本，比较核心指标和假设。
5. 输入来源、可信度和风险规则：已完成规则化风险等级、规则版本、结构化阈值和输入元数据展示，再接真实来源和 AI 解释。
6. 行动计划和任务追踪：已完成阶段化行动计划、确认写入和任务 ID 回显；跨页面持久化追踪后续结合任务来源筛选实施。
7. PDF 异步导出、短期下载链接、权限和分享：产品确认格式和会员策略后实施。

## 待确认问题

| 范围 | 当前 MVP 处理 | 需要产品/业务/算法确认 |
| --- | --- | --- |
| 计算公式 | 使用当前后端基础漏斗公式 | 月营收、CAC、LTV、ROI、回本周期和增长空间的正式口径 |
| 金额 | 使用整数人民币展示和存储 | 币种、含税/未税、最小货币单位及多币种规则 |
| 行业基准 | 未自动填充行业基准 | 行业分类、基准版本、数据来源和更新时间 |
| 风险等级 | 已输出版本化规则和结构化阈值 | 高/中/低阈值、风险维度和排序权重的正式取值 |
| 预测周期 | API 支持 1–36 个月，前端提供 3/5/12 个月快捷周期 | 正式默认周期和允许用户选择的周期集合 |
| AI 追问 | 当前为规则提取和固定问题 | AI 服务、超时重试、建议值来源和用户确认标识 |
| 导出 | 当前仅同步 JSON 下载 | PDF/PPT 是否首版支持、是否异步、有效期和水印 |
| 权限 | 按当前用户隔离模型 | 协作人/只读成员、分享和导出权限 |
| 历史筛选 | 已支持名称、分页、时间、业务类型、完成状态、风险，以及收入/利润率排序 | 业务类型的正式分类体系和归档状态工作流 |
| 任务生成 | 已有确认预览、幂等键、阶段上下文和任务 ID 回显 | 建议去重规则、责任人来源、截止日期、跨页面持久化状态和阶段映射 |

## 当前验证

- Go：增长模块、API 和鉴权路由定向测试通过。
- Web：增长 API、计算页、历史页、对比页测试通过；ESLint 和 TypeScript 检查通过。
- 浏览器：页面可加载；本地后端开发令牌未被 API 接受，需登录真实账号后再验证下载文件落盘。
