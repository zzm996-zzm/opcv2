# 工单中心参考设计

## 目标

将 `/help` 从帮助文档、反馈表单和工单记录的混合页面，重构为以工单处理为核心的工作台。页面沿用智活AI现有的 `V4PageShell`、品牌导航和真实 support API，信息架构参考用户提供的工单中心设计图。

## 页面结构

1. 顶部概览卡展示页面标题、说明、提交工单按钮和四项状态统计。
2. 工具区提供全部、处理中、已回复、待处理、已关闭五个状态筛选，以及按工单号或标题搜索。
3. 列表卡展示状态、主题、标题、工单号和最近更新时间；点击后打开只读详情弹窗。
4. 提交工单按钮打开弹窗，继续使用已有问题类型、标题、问题描述字段和创建接口。
5. 空列表、加载失败、提交失败和提交成功均使用页面内明确状态反馈。

## 数据边界

- 列表和创建继续使用 `GET/POST /api/v1/support/tickets`。
- 后端当前仅提供 `topic`、`title`、`body`、`status`、创建和更新时间，不伪造优先级、客服回复或关联产品。
- `open` 映射为待处理；处理中、已回复、已关闭兼容中英文状态值。
- API 返回空集合时保留现有参考工单用于视觉验收；筛选和搜索统一作用于当前可见工单集合。

## 响应式与验证

- 桌面端维持紧凑运营工作台布局，统计项横向排列，列表适合快速扫描。
- 平板端统计项两列排列；移动端改为单列，筛选标签可横向滚动，弹窗占满可用宽度。
- 测试覆盖数据渲染、状态筛选、搜索、详情打开、弹窗创建和空集合回退。
