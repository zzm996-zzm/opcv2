# 登录页 CSS 主视觉设计

## 目标

登录页以用户提供的参考稿为视觉基线，保留现有登录、注册、协议校验、错误反馈与登录后跳转逻辑。桌面端继续使用左右分栏：左侧承载品牌价值和视觉识别，右侧保持克制、清晰的登录表单。现有 `login-sculpture.jpg` 不再参与渲染，避免低分辨率图片放大、矩形边界和文字遮挡。

## 结构

左侧主视觉由语义为空的装饰 DOM 和 CSS 构成：两根渐变圆角柱形成悬浮 A 标，多层椭圆形成透明圆台，两条轨道承载发光粒子，三个半透明方块补足空间层次。动效仅包含 A 标浮动、轨道缓慢旋转、圆台呼吸光和方块小幅漂移；`prefers-reduced-motion` 下全部关闭。价值点使用 Lucide 图标，避免重复图标与手绘 SVG。

右侧表单宽度固定在参考稿的紧凑范围，账号和密码输入框增加图标，密码提供显隐控制。注册模式沿用原字段和滚动容器。移动端优先展示登录操作，压缩左侧叙事并隐藏次要价值列表，保证首屏不被装饰内容占满。

## 布局基准

桌面端以 `1672 × 945` 设计稿作为唯一坐标基准，左右栏固定为 `54% / 46%`。登录卡片基准尺寸为 `604 × 698`，在右栏内水平、垂直居中；品牌、主文案、能力列表和 CSS 主视觉使用设计稿坐标定位。视口高度不足 `945px` 时，整套内容按高度同比缩放，避免卡片固定高度顶满屏幕或左侧内容被单独压缩。窄屏仍使用独立的单栏布局，不沿用桌面缩放。

## 验证

测试覆盖原有登录注册流程及密码显隐。视觉验收使用 2048×1114、1366×768 和 390×844 三档视口，检查分栏比例、卡片尺寸、场景非空、文本不重叠、无横向溢出，并确认减少动态效果偏好生效。
